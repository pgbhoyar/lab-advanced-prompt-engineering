Use this after you have attempted a lab yourself. It points to the shared "improved" prompts that are the reference answers — they are the same assets the labs load, so nothing here is hidden.

  • Lab 01–08 reference prompts: see the prompts/ directory (each lab's improved, fewshot, defensive, or reference variant).

Compare your prompt against the reference on the same test cases and rubric — not by wording, but by whether it meets the required characteristics and passes deterministic checks.
