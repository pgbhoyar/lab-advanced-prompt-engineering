# Lab 00 — Portal Instructions

No local code is required. You will use the Microsoft Foundry portal.

## 1. Open the workshop project

1. Sign in to the Microsoft Foundry portal with the account provided for the workshop.
2. Open the workshop project and select the **workshop model deployment** (its name was provided
   by the facilitator; it may differ from "GPT-5.4").

## 2. Enter the prompt

1. Open the **Chat / Playground** experience for the selected deployment.
2. Leave the system/developer instructions empty for this baseline lab.
3. In the user message box, paste the baseline prompt with the request text substituted in:

   ```
   Look at this IT support message and tell me what to do about it.

   Hi, my laptop won't connect to the office WiFi since this morning. I've tried restarting.
   I have a client demo at 2pm and can't get online. Everyone else on my team seems fine.
   Can someone help? - Jordan, Sales
   ```

## 3. Run and record

1. Submit the message once.
2. Copy the response into [expected-observations.md](expected-observations.md).

## Checkpoint

- [ ] You received a response.
- [ ] You recorded two observable weaknesses.

## If something looks different

Portal labels change over time. If a control is named differently than described, look for the
nearest equivalent (model/deployment selector, system-instructions field, user-input box, Run/Submit).
If you are blocked, ask the facilitator or see [../../docs/troubleshooting.md](../../docs/troubleshooting.md).
