# Portal Setup (Microsoft Foundry)

The portal track requires **no local software** — only a browser and the workshop account.

## 1. Sign in

1. Open the Microsoft Foundry portal in a current desktop browser.
2. Sign in with the account provided for the workshop.

## 2. Open the project and deployment

1. Open the workshop project.
2. Locate the **model deployment** provided by the facilitator. Its name may differ from
   "GPT-5.4" — use the exact deployment name you were given.
3. Open the **Chat / Playground** for that deployment.

## 3. Where things are

Each lab's `portal.md` refers to these areas:

- **System / developer instructions** — stable behavior for the assistant.
- **User message** — the task and input for this run.
- **Structured output / JSON schema** option — used in Lab 04.
- **Run / Submit** — sends the request.
- **Copy** — copies the response for your worksheet.

## 4. If labels look different

Portal labels change over time. Prefer the nearest equivalent control and, if stuck, ask the
facilitator. Do not enter real or confidential data — use only the synthetic workshop inputs.
