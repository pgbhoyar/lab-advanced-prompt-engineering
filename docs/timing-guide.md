# Timing Guide (75 Minutes)

Three paths: **required** (fits 75 min), **accelerated** (if the group is fast), and **take-home**
(everything else). Core labs must fit without relying on optional challenges (SC-020).

## Required path (recommended agenda)

| Segment | Duration |
|---------|----------|
| Welcome, architecture, credential safety | 5 min |
| Lab 00 — Access & baseline | 8 min |
| Lab 01 — Explicit prompt contract | 10 min |
| Lab 02 — Instruction hierarchy | 10 min |
| Lab 03 — Few-shot prompting | 10 min |
| Lab 04 — Structured output | 15 min |
| Evaluation comparison + injection demo (Lab 07 highlights) | 10 min |
| Capstone intro + wrap-up | 7 min |
| **Total** | **75 min** |

Labs 05 (chaining) and 06 (grounding) are demonstrated briefly or assigned as take-home.

## Accelerated path (fast group)

If the group clears Lab 04 by the 45-minute mark, run Lab 05 or Lab 06 live (10 min each) before
the evaluation/injection segment.

## Take-home path

All labs, the full capstone, all three coding tracks, prompt chaining, grounding, adversarial
testing, and the consistency runs. Everything remains in the repository and works after the
temporary keys are rotated (assets are usable; only live calls require a key).

## Time-box checkpoints

- 20 min: everyone has a first model response (SC-001).
- 45 min: everyone has completed Lab 04 structured output.
- 68 min: capstone introduced.

If a checkpoint slips, drop the live demo of Labs 05–07 to demonstrations and keep the required
labs on track.
